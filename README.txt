Onuri 전체 소스 — 2026-10-28

기존 주소: https://cameo300.github.io/onuri/

구성
index.html: 프로필, 수업 안내, 포트폴리오, 문의
css/style.css: 반응형 디자인과 밝은/어두운 테마
js/script.js: 테마 선택, 갤러리 검색·분류·확대 보기
js/works.js: 작품 제목·분류·설명 관리
image/: 기존 작품 15점과 프로필 이미지

사용 방법
1. 압축을 풀고 index.html을 브라우저에서 열어 확인합니다.
2. GitHub cameo300/onuri 저장소 최상위에 같은 경로로 파일과 폴더를 올립니다.
3. Commit changes 후 GitHub Pages 배포가 끝나면 기존 주소에 반영됩니다.
별도 설치나 빌드 없이 사용하며 기존 QR 주소를 유지합니다.

내용은 최신 수정본이며 테마 선택은 사용하는 브라우저에 저장됩니다.
폰트는 인터넷 연결 시 Google Fonts에서 불러옵니다.
