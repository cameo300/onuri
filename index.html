01

사용하는 AI

아이디어와 콘텐츠를 만드는 데 활용합니다.

ChatGPT
대화로 아이디어와 콘텐츠를 만드는 생성형 AI. 아이디어·프롬프트 기획, 캐릭터·로고 이미지 제작, 글쓰기, 바이브코딩에 활용합니다.
Gemini
텍스트와 이미지를 함께 다루는 생성형 AI. 이미지 생성·변환, 캐릭터와 배경 구성, 동화 이야기 만들기, 수업 콘텐츠 정리에 활용합니다.
Claude
글과 코드를 함께 다듬는 생성형 AI. 콘텐츠 구성, 문장 다듬기, 바이브코딩을 통한 웹페이지 제작·수정에 활용합니다.
NotebookLM
업로드한 자료를 바탕으로 내용을 정리하고 질문하는 AI 학습 도구. 수업 자료 요약, 핵심 내용 정리, 자료 기반 질의응답과 교안 구성에 활용합니다.
02

사용하는 프로그램

디자인을 다듬고 결과물로 연결합니다.

Canva
템플릿을 활용해 시각 콘텐츠를 만드는 디자인 도구. 로고·상세페이지·디지털 문구·수업 자료를 제작합니다.
Inkscape
벡터 이미지를 만들고 편집하는 디자인 프로그램. 이미지를 SVG로 변환하고, 3D 굿즈와 레이저 제작용 도안을 다듬습니다.
Bambu Studio · MakerLab
Bambu Studio는 3D 출력 준비와 슬라이싱 프로그램, MakerLab은 제작 도구를 모아둔 웹서비스입니다. 간판 만들기 등으로 굿즈를 구성하고 출력으로 연결합니다.
RDWorks · xTool
레이저 장비의 가공 작업을 준비하는 프로그램·소프트웨어입니다. 사용 장비에 맞춰 각인·커팅 도안과 출력·속도 등 가공 조건을 설정합니다.
VS Code · GitHub
VS Code는 코드 편집기, GitHub는 코드 저장·버전 관리 플랫폼입니다. 웹페이지 파일을 수정하고 GitHub Pages로 배포합니다.
